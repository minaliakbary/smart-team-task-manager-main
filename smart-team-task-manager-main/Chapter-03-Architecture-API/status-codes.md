# HTTP Status Codes

## Project: Smart Team Task Manager

| Status Code | Meaning | Usage |
|---|---|---|
| 200 OK | Successful Request | Data retrieved or updated successfully |
| 201 Created | Resource Created | A new user or task has been created |
| 400 Bad Request | Invalid Request | The request contains invalid data |
| 401 Unauthorized | Authentication Required | The user is not authenticated |
| 403 Forbidden | Access Denied | The user does not have permission |
| 404 Not Found | Resource Not Found | The requested user or task does not exist |
| 500 Internal Server Error | Server Error | An unexpected server error occurred |
